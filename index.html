The 3-Tier Sarvam Pipeline

Chaining India's most capable foundation models for real-world agency.

STEP 1
Microphone Capture

16kHz audio recorded via sounddevice + native wave

STEP 2
Saarika STT

Transcribes Indic code-mix into normalized text

STEP 3
Sarvam-105B Brain

Extracts intent & generates strict JSON action schema

STEP 4
Execution & Bulbul

Runs command and speaks feedback in native language

Run it locally in 2 minutes

# 1. Clone repository & install requirements

git clone https://github.com/your-username/bhasha-os.git

pip install sarvamai python-dotenv sounddevice numpy


# 2. Add your Sarvam API Key to .env

echo "SARVAM_API_KEY=your_key_here" > .env


# 3. Launch the voice agent

python3 agent.py
